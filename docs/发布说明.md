# 公开版本与发布流程

## 发布内容

公开版是 Windows/Python 源码压缩包，包含运行源码、安装和任务脚本、无账号的配置模板、离线回归测试，以及安装、开发和安全说明。模板默认使用 Console 通知和人工验证码；日期偏移、场馆、开售时间和页面选择器都是示例，使用者需现场核对。

项目暂未指定开源许可证。本版本不附加 MIT、Apache 或其他授权文本；后续确定许可证时需同时更新公开文件清单和包元数据。

发布包没有 `.git`、本机配置、运行记录、浏览器登录状态或构建者路径。原工作目录可以继续保留这些私有数据。不要直接压缩原目录上传。

## 生成与核验

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts/build_public_release.py --check
.\.venv\Scripts\python.exe scripts/build_public_release.py
```

默认生成 `dist/buaa-badminton-booking-0.1.0-public.zip` 和同名 `.sha256` 文件。包内 `SHA256SUMS` 记录每个公开文件的摘要，供解压后核对。打包使用明确的文件清单，不依赖 Git 是否追踪某个文件，也不读取凭据库或私有配置；拒绝清单中的链接、重解析点及常见敏感内容模式。模式扫描不是所有秘密的通用检测器，修改后仍需审阅新增内容。

压缩包是推荐的公开上传对象。若需要公开 Git 仓库，先把包解压到新的空目录，仅在该目录初始化新仓库，再提交和推送。旧仓库历史曾包含调试文件，未对全部历史作无泄露认证，因此不要直接把原仓库设为公开或推送其历史。原仓库无需删除或改写。

## 干净目录检查

解压到独立目录后，在该目录创建虚拟环境、执行安装步骤并运行离线测试。`init` 只应在新目录创建本机配置；离线测试和发布检查无需该文件。对照 `SHA256SUMS` 检查解压文件内容；`.sha256` 校验整个 ZIP。

安装任务脚本会注册/覆盖当前用户的四个固定名称任务，并立即启动 Dashboard。只有在配置和凭据完成后主动执行该脚本；不要在验证发布包时安装任务。`run` 会创建真实订单，离线检查不会验证真实预约、OCR 成功率、支付或手机送达。

## 当前验证范围

发布准备包括离线浏览器回归、命令帮助、配置模板加载、源文件语法、PowerShell 语法、包内容和摘要核对。真实网站结构、开售时间和现场运行需要使用者另行校准；离线测试通过不代表现场预约保证成功。
